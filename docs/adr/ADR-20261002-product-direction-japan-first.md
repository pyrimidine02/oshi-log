# ADR-20261002: 일본 메인 제품 방향과 5탭 정보구조

## 상태

Accepted — 2026-10-02 (사용자 결정)

## 문제

앱은 기능별로 확장되며 정보 탭·탐방 탭에 서로 다른 성격의 기능이 섞였다. 시장 전제도 한국 중심이었으나 실제 메인 서비스 대상은 일본이다.

## 결정

- 메인 시장은 **일본**, 한국은 **가오픈**(설치·인증·저장·현장 사용 안정성 검증)으로 운영한다. JP/KR 지표는 분리한다.
- 핵심 루프는 탐색 → 준비 → 현장 → 기록이다.
- 하단 5탭: **홈 / 지도 / 라이브 / 커뮤니티 / 마이**. 정보 탭의 음악·아티스트·응원법·캘린더는 라이브 탭으로 흡수한다. 커뮤니티 진입 시 하단 바 교체는 없앤다.
- **티켓 접수 회차·마감·당락·입금 관리와 마감 알림은 범위에서 제외**한다. 공연 상세에는 공식 티켓 링크만 둔다.
- **정보 밀도는 조밀하게 하지 않는다.** 목록 행은 날짜·제목·상태 중심, 나머지는 상세로.
- 여행·성지순례 보강(원문 제시, 매너, 장면 근거, 지역 허브, 기간 한정 스폿, 당일 목록, 여행 앨범)은 `screen-design-v1.md` §3.4 우선순위를 따른다.

## 대안

- 정보 탭 유지(음악 독립 탭): 음악 탐색 독립 수요가 검증되면 재검토.
- 티켓 마감 관리 포함: 일본 推し活 도구의 핵심 기능이지만 사용자 결정으로 제외.
